# Retro LCD / Amber

Vintage amber LCD dashboard for the Universal Screen 8.8-inch in horizontal 1920×480 orientation. A large seven-segment 24-hour clock is accompanied by separate seconds, a day-month-year date and abbreviated weekday. Three adjacent LCD panels show CPU/GPU temperatures, CPU/GPU utilization and RAM utilization with horizontal bars.

Install from Browse Online Templates and confirm the five detected sensor categories. All eight sensor-bearing widgets use portable sensor_category hints; installation assigns the selected sources and removes those hints. Unavailable categories show N/A or empty bars until assigned in the editor. The portable JSON must not be copied directly into the installed template list without resolving those categories.

The clock uses the renderer's local time. The abbreviated weekday follows the clock formatter's locale support. Percentages use a 0–100 range. Values and the clock update live; amber illumination, bezel and screws are static original artwork. No command sensors or network access are required for playback.

The bundled DSEG7 Classic Bold and Rajdhani SemiBold fonts are loaded from this folder, so no system font installation is required. Both retain SIL OFL 1.1 notices; see CREDITS.md.

The layout was approved by @marvinduranr on a Universal Screen 8.8-inch (horizontal 1920×480), running Lian Li Linux 1.2.4 in a Fedora 44 Distrobox on Bazzite with an AMD RX 9070 XT. The local installer reused already-bound sensors and cleared the portable markers. Full installation through the upstream catalog remains untested until publication.
