# Cyber Rain / Mustard

Bright mustard/red rainy-city dashboard for the Universal Screen 8.8-inch in horizontal 1920×480 orientation. Analog CPU/GPU load gauges, temperature readouts, download/upload gauges, RAM utilization/capacity, free storage, NVMe temperature and a seconds clock.

CPU/GPU/RAM usage and network widgets use documented sensor_category hints and neutral sources. Download/upload bind to the default-route interface at catalog installation. Network readings include all interface traffic in decimal MB/s. Both network dials use a fixed 0–125 MB/s scale (1 Gbit/s equivalent); numeric readings can exceed that scale while needles saturate. Update bindings after changing the active interface or VPN.

RAM capacity is the kernel-visible MemTotal in GiB, rounded to a whole number, rather than the installed DIMM capacity printed on its packaging. It may read 31 GiB on a machine sold with 32 GB RAM. A read-only awk command reads /proc/meminfo. FREE uses a read-only df/awk command to show available GiB on the daemon account's home filesystem; it does not total multiple disks. These commands require standard Linux df/awk tools in the daemon environment. Readouts update every 10 seconds; command sampling is managed independently by the daemon.

SSD temperature selects a hwmon chip named nvme with its Composite label and no machine-specific PCI path. Systems without that sensor show no reading; on systems with multiple NVMe devices, select the intended sensor in the editor. The readout updates every five seconds. No CPU/GPU category is applied to the SSD.

Tested locally by @marvinduranr on Bazzite with Lian Li Linux v1.2.0 and a Universal Screen 8.8-inch (1920×480, rotated). The layout was approved on the physical screen and the SSD sensor was resolved successfully after correcting its binding. The local RAM capacity label was 32 GB; this catalog version reads kernel-visible capacity automatically. Full installation from the upstream Template Browser remains untested.

The preview is a JPEG generated by the native render-preview tool at full 1920×480 resolution to stay under the browser's 1 MiB preview-download limit. Artwork/font credits are in CREDITS.md.
